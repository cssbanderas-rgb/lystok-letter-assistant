# ЛистОК

Помічник ділового листування українською для працівників і підприємців.
Перетворює чернетку на тему та текст листа у нейтральному, дружньому або
офіційному тоні. Не надсилає листи. Використовує OpenRouter `openrouter/free`.

## Запуск

Python 3.10+, рекомендовано 3.12.

```sh
pip install -r requirements.txt
python app.py
```

Перед запуском задайте змінну середовища `OPENROUTER_API_KEY` у своєму
середовищі. Не додавайте ключ у файли, git, скриншоти чи чат.
Локальна сторінка: http://127.0.0.1:7860. На хостингу підтримується змінна `PORT`.

## Hugging Face

SDK Gradio, entrypoint `app.py`. Додайте `OPENROUTER_API_KEY` через Settings →
Variables and secrets → New secret. У перевіреному акаунті 27.10.2026 створення
Gradio Space вимагає PRO, тому для безкоштовної публікації розглядаємо Render.

## Render (Free)

Новий Web Service із публічного git-репозиторію. Runtime Python 3,
build `pip install -r requirements.txt`, start `python app.py`, instance Free.
Додайте `OPENROUTER_API_KEY` у Environment як секрет. Безкоштовний сервіс
може засинати, тому перше відкриття після простою може тривати довше.

## Безпека й обмеження

- Ключ читається тільки на сервері; поля для введення ключа в застосунку немає.
- Чернетка передається OpenRouter та постачальнику обраної моделі.
- Не вводьте конфіденційні дані, паролі й токени.
- Застосунок не записує чернетки у файли чи власну базу даних.
- Вивід — звичайне текстове поле, HTML моделі не виконується.
- Введення обмежене; є таймаут, обмежена черга й один паралельний запит.
- Інструкція забороняє додавати факти й вимагає позначати пропуски, але
  промпт не гарантує відсутності вигадок. Перед надсиланням перевіряйте лист.
- Безкоштовні моделі можуть бути недоступні або мати ліміти.
- Публічний сервіс доступний усім; для тривалого використання варто додати
  автентифікацію та стійке обмеження частоти запитів.

## Перевірки

```sh
python -m unittest -v
```

Тести використовують підміну мережі та не підтверджують якість живої LLM.
Для ручної перевірки є три приклади в інтерфейсі. Очікується збереження
чисел у першому, зміна лише тону у другому, позначення відсутньої дати й
номера замовлення у третьому.
